## 리뷰 결과: 고친 뒤 합치기

지시서가 요구한 것은 모두 들어 있고, 요구하지 않은 것은 없다. 코드 문제는 찾지 못했고 문서 한 줄만 고치면 된다.

### 꼭 고칠 것
- [docs/testing.md:30] `tests/unit/test_migrations.py` 줄의 셀 구분이 잘못됐다. 빈출질문 마이그레이션 설명을 설명 셀 끝에 잇지 않고 `| 빈출질문 테이블(...)... | PostgreSQL |`처럼 새 셀로 넣어서 이 줄만 셀이 4개다. 표는 3열이라 세 번째 열에 "PostgreSQL" 대신 빈출질문 설명이 나온다. 바로 앞의 `| `를 지우고 ". 빈출질문 테이블(...)..."로 설명 셀에 이어 쓴다.

### 고치면 좋은 것
- [backend/app/db.py 끝] `FrequentQuestionRow`가 다른 모델들 사이가 아니라 `make_engine()` 뒤, 파일 맨 끝에 있다. 동작에는 문제가 없지만 모델 정의 영역으로 옮기면 찾기 쉽다.

### 테스트
- 리뷰어는 직접 돌리지 않았다. 개발자 보고(백엔드 81개, 프런트엔드 106개 통과, build 통과, lint 오류 없음)를 믿었다.
