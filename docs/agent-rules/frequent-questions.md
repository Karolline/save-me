# 빈출 문항 작성법

자소서·면접에서 자주 나오는 문항을 어떤 구조로 답할지 사용자가 정한 팁 모음. `doc-writer`가 해당 문항을 쓸 때 따르는 기준이다. 사용자가 직접 꺼내 보기도 한다.

- **A(공식)와 요소의 "뜻"은 사용자가 쓴 것**이다. AI가 바꾸지 않는다.
- "재료 찾는 곳"과 "주의"는 AI가 SaveMe 구조에 맞춰 덧붙인 것이다. 사용자가 고쳐도 된다.
- 재료는 `agent_read` 조회 명령으로 읽는다 (`backend/` 안에서 `uv run python -m app.agent_read ...`). 조회 결과에 없는 재료는 지어내지 않고 작성메모의 "판단이 필요한 부분"에 "○○ 재료 필요"로 남긴다.
- 새 문항은 맨 아래 형식대로 더한다.

## 지원동기

**A:** 나는 **ㅇㅇ** 성장을 하고 싶고, 이 회사는 **ㅁㅁ** 기회가 있고, 그래서 내 **ㅂㅂ** 경험으로 이 회사의 **ㅍㅍ**를 키우고 싶다.

| 요소 | 뜻 (사용자) | 재료 찾는 곳 (AI) |
|---|---|---|
| ㅇㅇ | 내가 3년 뒤 어떤 사람이 되고 싶은지 | `profile`의 커리어 방향, `personality`의 장래·포부 류 답변 |
| ㅁㅁ | 채용공고, 기술블로그, 기사, 서비스 직접 써본 경험 | `job <ID>`의 공고 원문과 회사 동향. 기술블로그·기사·서비스 사용 경험은 사용자에게 받아야 하는 재료다 |
| ㅂㅂ | 내가 실제로 성과 낸 경험 하나 | `experience-index`에서 고른 `experience <ID>` 하나. `상황/과제/행동/결과` 본문 근거 |
| ㅍㅍ | 이 회사가 지금 키우려는 사업이나 약점 | 공고분석의 핵심 과제, 공고 원문의 사업·조직 소개, 회사 동향의 어필 포인트 |

**주의 (AI)**
- ㅁㅁ의 "서비스 직접 써본 경험", "기술블로그에서 읽은 내용"은 조회 결과에 없으면 지어내지 않는다. 작성메모에 "ㅁㅁ 재료 필요"로 남기고, 공고 원문과 출처가 달린 회사 동향으로만 쓴다.
- ㅂㅂ은 경험 하나로 끝낸다. 여러 경험을 나열하지 않는다.
- ㅍㅍ는 약점을 쓰더라도 회사를 깎아내리는 표현이 아니라 "키우려는 영역"으로 쓴다.
- ㅇㅇ에서 현재 회사를 낮추는 것으로 읽히는 표현은 피한다. 이직 사유가 핏 문제로 읽히면 면접에서 불리해진다.

## 직무 적합 이유

"본인이 이 직무에 적합한 이유", "직무 역량", "왜 이 직무에 맞는 사람인가" 류 문항.

**A:**
1. 기본기: **[전공/경험]**으로 이 직무에 필요한 기본기를 갖췄다
2. 증거: **[프로젝트]**에서 **[핵심역량]**을 써봤고 **[성과]**를 얻었다 (가장 중요)
3. 일치: 이 직무가 요구하는 역량이 내가 제일 자신 있는 부분과 겹친다
4. 방향: 할 수 있다를 넘어서 이 직무로 **[목표]**를 이루고 싶다

| 요소 | 뜻 (사용자) | 재료 찾는 곳 (AI) |
|---|---|---|
| 기본기 [전공/경험] | 이 직무에 필요한 기본기를 갖췄다는 근거 | `profile`의 학력·경력 요약 |
| 증거 [프로젝트]·[핵심역량]·[성과] | 실제로 그 역량을 써서 낸 성과 (가장 중요) | `experience <ID>`: 공고 핵심 요구에 가장 맞는 경험 하나. 성과·수치는 `결과` 본문에 있는 것만 |
| 일치 | 직무 요구 역량과 내가 가장 자신 있는 부분이 겹친다 | `job <ID>`의 핵심 요구 역량과 증거에서 쓴 역량 |
| 방향 [목표] | 이 직무로 이루고 싶은 것 | `profile`의 커리어 방향, `personality`의 장래·포부 류 답변 |

**주의 (AI)**
- 분량은 증거에 가장 많이 쓴다. 기본기·일치·방향은 짧게 둔다.
- 증거는 경험 하나로 끝낸다. 성과 수치는 `결과`에 없으면 쓰지 않는다.
- 일치의 "제일 자신 있는 부분"은 증거에서 보여준 역량과 같은 것이어야 한다. 증거와 상관없는 강점을 새로 꺼내지 않는다.
- 같은 자소서에 지원동기 문항이 따로 있으면, 방향의 [목표]가 지원동기의 ㅇㅇ과 같은 말이 되지 않도록 표현을 나눈다.
