기획 시간에는 사용자가 답한 시간이 들어 있다. 프로세스 합은 명령과 그 자식 프로세스의 작업 집합(working set)을 더한 값이라 공유 메모리가 겹쳐 세어진 대략의 위쪽 값이다. PC 전체 증가는 실행 중 PC의 사용 중인 물리 메모리가 시작 때보다 가장 많이 늘어난 양으로, Docker(WSL)에 띄운 PostgreSQL 컨테이너도 포함한다. 리뷰는 읽기 위주라 직접 돌린 테스트가 없으면 메모리 기록이 없다.
